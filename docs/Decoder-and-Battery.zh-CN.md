# 解码器与省电设置说明

如果你只是想流畅播放视频，同时尽量减少耗电和发热，建议先使用下面这套配置：

1. 进入“设置 → 解码器 → MPV 配置档”，选择“快速”。
2. 关闭“使用 `gpu-next`”。
3. 关闭“使用 Vulkan”。
4. 关闭 Anime4K 和其他自定义着色器。
5. 不熟悉 `mpv.conf` 时，先让它保持为空。

只要播放流畅、画面正常，就不必为了看起来“参数更高级”而打开更多选项。

本文根据 mpvRx 的 [mpv 电池优化指南](https://github.com/Riteshp2001/mpvRx#-battery-optimization-guide-for-mpv) 汉化并整理。原文包含作者个人的实测经验，不同手机、系统和视频的结果可能不同。

## 先分清三个容易混淆的概念

- **硬件解码**：由手机芯片中的专用模块负责解压视频，通常比软件解码更省电。应用里的“尝试硬件解码”控制的是这一项。
- **`gpu` / `gpu-next`**：负责把解码后的画面渲染到屏幕上。它们是渲染后端，不是视频解码器。
- **OpenGL / Vulkan**：GPU 使用的图形接口。开启 Vulkan 不等于开启硬件解码，也不保证一定更快或更省电。

因此，“硬件解码已经开启”和“是否使用 Vulkan”是两件不同的事。

## 为什么推荐这些设置

### 1. MPV 配置档选择“快速”

“快速”配置档会优先保证播放性能，适合手机日常观看。可以直接在应用里选择，也可以在 `mpv.conf` 中写入：

```conf
profile=fast
```

两种方式选一种即可。新手更建议直接使用应用内的“MPV 配置档”，不必手动编辑配置文件。

### 2. 普通播放优先使用经典 `gpu` 后端

原作者建议普通视频优先使用经典 `gpu`，而不是 `gpu-next`。在不少 Android 设备上，经典后端的兼容性和功耗表现更稳妥。

这不代表 `gpu-next` 一定有问题。只有在你明确需要它的功能，并确认设备播放稳定、耗电可以接受时，才有必要开启。

### 3. 不需要时关闭 Vulkan

Vulkan 可以在部分设备或特定渲染场景中改善性能，但也可能增加负载、发热或兼容性问题。如果使用默认 OpenGL 已经能流畅播放，就没有必要只为了“性能可能更高”而开启 Vulkan。

### 4. 少用不必要的着色器

Anime4K 和其他 GLSL 着色器会让 GPU 继续处理每一帧画面。播放 24 fps 视频时，每秒有 24 帧都要经过额外处理；效果叠得越多，通常越耗电，也越容易发热和掉帧。

着色器不是越多越好。手机屏幕较小，有些效果很难看出区别，但性能代价却是真实存在的。

### 5. 不要直接照搬复杂的网络配置

网上有些 `mpv.conf` 同时包含复杂缩放算法和多条着色器，例如：

```conf
scale=ewa_lanczossharp
dscale=mitchell
cscale=sinc
glsl-shaders=...
```

这些参数可能是为电脑、大屏幕或特定片源准备的，不一定适合手机。整份复制后如果出现耗电、发热或卡顿，也很难判断是哪一项造成的。

更稳妥的方法是从空配置开始，每次只增加一个自己确实需要的选项，并在修改后实际播放一段视频。

## 耗电异常时怎么排查

建议使用同一部视频、相近的屏幕亮度和网络条件进行对比，然后按顺序操作：

1. 关闭 Anime4K 和其他自定义着色器。
2. 关闭 Vulkan 和 `gpu-next`，改回经典 `gpu` 后端。
3. 把 MPV 配置档改为“快速”。
4. 暂时清空自定义 `mpv.conf`。
5. 确认“尝试硬件解码”已开启，并观察该视频是否能正常使用硬件解码。
6. 降低屏幕亮度，或改用本地视频排除网络耗电的影响。

每次只改一项，才能看出真正有效的是哪一步。

## 怎样判断功耗是否合理

原文给出的个人经验参考值是约 **200 mAh、0.9 W 以下**，并认为观看两小时电影耗电不应明显超过 **20%～25%**。不过原文没有完整说明测试时长、设备和屏幕亮度，因此这些数字只能用作参考，不能当作所有手机都必须达到的标准。

真正有用的判断方法，是在自己的设备上用同一视频做前后对比。如果关闭复杂渲染后温度下降、掉帧减少、单位时间耗电降低，就说明精简配置确实有效。

## 按需求选择

| 你的目标 | 建议设置 |
|---|---|
| 省电、低温、稳定播放 | “快速”配置档 + 经典 `gpu`，关闭 Vulkan 和着色器 |
| 使用 Anime4K | 从较轻的预设和“快速”变体开始，接受额外耗电与发热 |
| 排查卡顿或异常耗电 | 恢复默认或空配置，再一次只启用一项功能 |
| 默认设置已经流畅 | 保持现状，不必继续增加渲染选项 |

需要使用 Anime4K 时，请继续阅读 [Anime4K 使用说明](Anime4K.zh-CN.md)。
