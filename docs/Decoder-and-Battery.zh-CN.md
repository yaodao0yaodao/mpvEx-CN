# 解码器、HDR 与省电说明

## 三种解码模式

- **硬件解码**：兼容性与功能最均衡，通常应作为首选。
- **软件解码**：由 CPU 解码，兼容疑难片源，但高分辨率视频可能更耗电；进入该模式时自动使用“快速”配置档。
- **硬件解码增强**：MediaCodec 直接输出，适合只有零拷贝才能流畅播放的高码率 4K 视频，通常也最省电。为了显示字幕，该路径会把 HDR 转成 SDR，因此控件显示的片源 HDR 类型不等于真正的 HDR 屏幕输出。

“设置 → 解码器 → 解码器优先级”决定每个文件的尝试顺序。硬件解码增强默认不启用，老用户升级后也必须主动勾选并阅读兼容提示。一次 fallback 流程中每种解码器最多尝试一次，全部失败后停止并显示播放失败。

播放界面的解码器控件只临时切换本次播放器，不会改写优先级；退出播放后失效。使用软件解码或硬件解码增强时自动应用“快速”配置档；直播不论采用哪种解码器都自动应用“低延迟”配置档。手动修改配置档仍可覆盖当前播放，下一次进入相应场景时重新应用自动档位。

## 硬件解码增强的功能限制

硬件解码增强可以与 `gpu-next` 同时使用，但画面无法进入需要 GPU 中间纹理的处理链，因此播放期间：

- Vulkan 临时不可用，播放界面开关变灰，但永久设置不变；
- Anime4K / ArtCNN 不可用；
- 线性 HDR 与 SDR→HDR 增强不可用；
- HDR 控件只显示片源的 PQ、HLG 或 BT.2020 类型；SDR 片源会提示增强不可用。

切回硬件解码或软件解码后，保存的 Vulkan、AI 超分辨率和 SDR→HDR 设置重新生效。

## SDR→HDR 增强

普通硬件解码或软件解码下，原生 HDR 片源自动使用线性 HDR；用户无需选择 PQ、HLG、BT.2020 等模式。SDR 片源可单击播放界面的 HDR 控件开启或关闭 SDR→HDR 增强，该控件就是永久开关，设置页不再重复提供选项。

## 自动控制

播放器不再读取温度，也不会与 Android 系统的降频或亮度保护争夺控制权。它只比较实际渲染进度与片源帧率（倍速时按倍速修正）。暂停、拖动、缓冲或缓存断流会清空本轮计时；恢复正常播放后必须连续低于目标 10 秒才降一级，每降一级再观察 10 秒。

降级顺序为：取消倍速 → 高质量/默认/快速配置档逐级降低 → 关闭 AI 超分辨率 → 停止记忆屏幕亮度 → 关闭 SDR→HDR 增强 → 最后尝试硬件解码增强。已经满足的步骤立即跳过，不浪费观察周期。

自动控制只降不升，所有调整都是当前文件的临时状态。切换视频、离开播放器或销毁播放器后恢复；用户在自动控制期间主动做出的临时修改会成为新的恢复基线。若硬件解码增强未在优先级中启用，或已经在当前文件上失败过，自动控制绝不会再切换到它。

## 省电建议

1. 优先使用硬件解码与“快速”配置档。
2. 不需要 AI 超分辨率、SDR→HDR 或 GPU 去色带时保持关闭。
3. Vulkan 和 `gpu-next` 并不等于硬件解码；默认 OpenGL 已流畅时无需为了参数更“高级”而开启。
4. 高码率视频只有零拷贝才流畅时，再主动启用硬件解码增强。
5. 电量每次从不低于 30% 跨到低于 30% 时，播放器会弹窗说明硬件解码增强的省电优势；可关闭当次弹窗或永久不再提醒。
