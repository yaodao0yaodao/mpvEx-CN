# mpvEx 的 Anime4K 使用说明

Anime4K 是面向动漫和动画内容的实时放大与画面修复方案。本项目内置了来自
[bloc97/Anime4K](https://github.com/bloc97/Anime4K) 的 GLSL 着色器，并将常用着色器链组合为 A、B、C 及其增强预设。

> Anime4K 在本应用中仍属于实验性功能。它会显著增加 GPU 负载、耗电与发热，实际效果也会随片源和设备而变化。

## 如何启用

1. 在“设置 → 高级”中启用高级功能。
2. 打开“设置 → 解码器 → Anime4K 放大（实验性）”。
3. 播放视频后，在播放器“更多选项”中选择 Anime4K 预设和变体。

4K 或更高分辨率视频会禁用播放器内的预设与变体选项。使用 `gpu-next` 时应同时使用 Vulkan；非 Vulkan 的 `gpu-next` 不加载 Anime4K 着色器。

## 预设说明

下表描述的是本项目实际加载的着色器链，而不是抽象的画质等级。

| 预设 | 本项目中的处理链 | 适合场景 | 可能的副作用 |
|---|---|---|---|
| 关闭 | 不加载 Anime4K 着色器 | 原始画面或性能不足时 | 无 Anime4K 处理 |
| A | 细节修复 → 放大 → 自动缩小准备 → 再次放大 | 线条较清楚、希望强化细节的动画 | 可能过度锐化或放大压缩瑕疵 |
| B | 柔和修复 → 放大 → 自动缩小准备 → 再次放大 | 线条较柔和、希望减少锐化感的动画 | 细节增强弱于 A |
| C | 降噪放大 → 自动缩小准备 → 再次放大 | 噪点、色块或压缩痕迹较明显的片源 | 可能抹去细线或纹理 |
| A+ | 细节修复 → 放大 → 自动缩小准备 → 再次细节修复 → 放大 | 低分辨率且线条清楚的片源 | GPU 负载更高，锐化更明显 |
| B+ | 柔和修复 → 放大 → 自动缩小准备 → 再次柔和修复 → 放大 | 需要更强处理但不希望过锐 | GPU 负载更高，画面可能偏软 |
| C+ | 降噪放大 → 自动缩小准备 → 细节修复 → 放大 | 同时需要降噪和线条恢复的片源 | 最容易改变原始画面观感 |

简单选择方法：先尝试 B；画面偏糊时改用 A，压缩噪点明显时改用 C。只有 GPU 余量充足且普通预设效果不够时，再尝试对应的“+”预设。

## 变体说明

变体决定神经网络着色器的规模。它不会改变 A、B、C 的处理顺序。

| 变体 | 内部后缀 | 特点 | 建议 |
|---|---|---|---|
| 快速 | S | 网络最小，GPU 压力和耗电最低 | 手机、平板或高帧率视频优先 |
| 均衡 | M | 画质与性能折中 | 性能足够时作为首选 |
| 高质量 | L | 网络最大，细节处理最强，GPU 压力最高 | 高性能设备、低分辨率或低帧率片源 |

如果出现掉帧、音画不同步、明显发热或耗电过快，请依次降低变体、改用非“+”预设，或关闭 Anime4K。Anime4K 不能补回片源中不存在的真实细节，建议以自然、稳定播放为准。
