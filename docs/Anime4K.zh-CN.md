# Anime4K 使用说明

Anime4K 可以在播放动漫时实时放大画面，并对线条、噪点和压缩痕迹做一些修整。它不是简单地把画面拉大，而是让 GPU 对每一帧继续加工，因此通常会增加耗电和发热。

如果你只想快速选一个方案，可以从这里开始：

- 普通手机：先选 **B + 快速**。
- 画面比较糊、线条不清楚：试试 **A + 快速**。
- 噪点、色块或压缩痕迹明显：试试 **C + 快速**。
- 出现掉帧、音画不同步或手机明显发热：降低变体，或直接关闭 Anime4K。

> Anime4K 是实验性功能，不能凭空还原片源里原本不存在的细节。自然、流畅的画面通常比更强的锐化更重要。

## 如何开启

1. 进入“设置 → 高级”，打开高级功能。
2. 进入“设置 → 解码器”，打开“Anime4K 放大（实验性）”。
3. 开始播放视频。
4. 打开播放器的“更多选项”，选择 Anime4K 的“预设”和“变体”。

4K 及更高分辨率的视频不会提供播放器内的预设和变体选项，因为这类视频本身已经很清晰，继续放大通常只会大幅增加 GPU 压力。

如果使用 `gpu-next`，需要同时开启 Vulkan；`gpu-next` 与 Vulkan 没有同时启用时，应用不会加载 Anime4K 着色器。

## “预设”和“变体”有什么区别

- **预设**决定怎么处理画面。A 偏向强化线条，B 更柔和，C 偏向降噪；带“+”的版本处理更重。
- **变体**决定处理强度和运算量。快速最省性能，均衡居中，高质量最吃性能。

可以把它们理解成：先用“预设”选择处理方向，再用“变体”选择手机要为此付出多少性能。

## 预设怎么选

| 预设 | 画面效果 | 适合什么视频 | 需要注意 |
|---|---|---|---|
| 关闭 | 保持原始画面 | 原片已经清晰，或设备性能不足 | 不进行 Anime4K 处理 |
| A | 更强调线条和细节 | 线条清楚但分辨率偏低的动画 | 可能显得太锐，也可能把压缩痕迹一起放大 |
| B | 比 A 柔和、自然 | 大多数普通动画，或不喜欢锐化感时 | 细节增强没有 A 明显 |
| C | 先压低噪点，再放大 | 有噪点、色块或压缩痕迹的片源 | 可能把细线和纹理一起抹平 |
| A+ | 更强地强化线条和细节 | 低分辨率、线条清楚，而且设备性能充足 | 比 A 更耗性能，也更容易过度锐化 |
| B+ | 更强的柔和修复 | 普通 B 效果不够，但又不想画面太锐 | 更耗性能，画面可能偏软 |
| C+ | 同时加强降噪和线条恢复 | 画质较差，既有噪点又缺少清晰线条 | 最耗性能，也最容易改变原片风格 |

不知道选什么时，先用 **B**。觉得画面仍然偏糊就换 **A**，噪点明显就换 **C**。只有普通预设效果不够，而且播放仍然流畅时，再尝试对应的“+”预设。

## 变体怎么选

| 变体 | 性能占用 | 适合情况 |
|---|---|---|
| 快速 | 最低 | 建议手机和平板优先使用；也适合高帧率视频 |
| 均衡 | 中等 | 快速变体效果不够，而且设备仍有性能余量时 |
| 高质量 | 最高 | 高性能设备播放低分辨率、低帧率片源时尝试 |

“高质量”不一定看起来最好。手机屏幕较小，画质差别可能并不明显，但耗电、发热和掉帧会更容易察觉。

## 播放不流畅怎么办

按下面的顺序逐项尝试，每做一步就重新观察播放是否恢复正常：

1. 把“高质量”改为“均衡”或“快速”。
2. 把 A+、B+、C+ 改为对应的 A、B、C。
3. 改用更轻的 B 或直接关闭 Anime4K。
4. 同时关闭其他自定义着色器，避免多套效果叠加运行。

## 技术信息与许可

本项目内置 [bloc97/Anime4K](https://github.com/bloc97/Anime4K) 的 GLSL 着色器，并把常用处理步骤组合成 A、B、C 及其增强预设。想了解应用实际加载了哪些着色器，可以查看 [Anime4KManager.kt](../app/src/main/java/app/marlboroadvance/mpvex/domain/anime4k/Anime4KManager.kt)。

着色器的版权与许可遵循 Anime4K 源项目；本文只说明 mpvEx 如何使用这些着色器。
