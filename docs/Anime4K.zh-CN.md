# AI 超分辨率说明

播放器内置 Anime4K 与 ArtCNN，两者都会用 GPU 实时处理视频画面，适合放大低分辨率动画。它们不是解码器，也不能凭空恢复片源中不存在的细节；开启后会增加耗电、发热和掉帧风险。

播放界面的 **AI 超分辨率** 控件默认位于解码器控件右侧。Anime4K 功能本身始终可用，不再需要先去设置中打开总开关。选择会保存；播放器的自动控制只可能在当前文件内临时关闭它，不会改写保存的选择。

## 什么时候会真正启用

播放器以自动剪切黑边后的有效画面作为输入，并与实际显示区域比较。只有输出宽度或高度至少需要放大约 `1.2×` 时才加载着色器；如果原视频已经接近屏幕分辨率，控件中的选择仍会保留，但本次播放会临时跳过处理。切换视频后重新计算。

硬件解码增强采用直接输出路径，无法插入 Anime4K/ArtCNN 着色器。该模式下控件会变灰并说明不可用，切回硬件解码或软件解码后恢复。

## Anime4K 预设

Anime4K 预设可再选择“快速、均衡、高质量”三个质量档：

| 预设 | 主要效果 | 建议 |
|---|---|---|
| A | 恢复线条后放大 | 线条清楚、分辨率偏低的动画 |
| B | 较柔和地恢复后放大 | 大多数普通动画，建议先尝试 |
| C | 先降噪再放大 | 噪点、色块或压缩痕迹明显的片源 |
| C+ | 更重的降噪与线条恢复 | 画质较差且设备性能充足时尝试 |

“快速”最适合手机日常使用；“高质量”运算量最高，不代表肉眼效果一定最好。A+、B+ 已移除，避免提供效果重叠但负载更高的选项。

## ArtCNN 模型

ArtCNN 是与普通 Anime4K 不同的固定神经网络模型，不使用 Anime4K 的质量档，也不会被自动改成 A/B/C：

| 模型 | 用途 |
|---|---|
| ArtCNN C4F32 普通版 | 中性的 2 倍亮度放大 |
| ArtCNN C4F32 DN | 放大并降噪，结果更柔和 |
| ArtCNN C4F32 DS | 放大并降噪、锐化 |
| AniSD ArtCNN C4F32 普通版 | 面向标清动画训练的模型 |
| AniSD ArtCNN C4F32 CMP | AniSD 的计算着色器版本，现代 Vulkan GPU 上可能更快 |
| Ani4Kv2 ArtCNN C4F32 CMP | 面向 4K 动画重建的官方计算着色器原版 |

其中计算着色器（CMP）通常需要 Vulkan；不支持时请改用非 CMP 模型或普通 Anime4K。

## 卡顿时怎么办

先把 Anime4K 质量改为“快速”，再尝试 B 或 C；ArtCNN 卡顿时只能换用更轻的模型或关闭，不能降级成普通 Anime4K。播放器还会监测实际播放帧率：连续 10 秒低于片源帧率的 95% 才进行一次临时降级，并在每次降级后重新观察，不会因为短暂缓冲、暂停或拖动进度条而误判。
